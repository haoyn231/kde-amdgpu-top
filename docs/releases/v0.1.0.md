# kde-amdgpu-top v0.1.0

首个公开版本：一个面向 KDE Plasma 6 的 AMD GPU 面板监视器，数据来自 `amdgpu_top`，交互与数据语义参考 [kde-perfmon](https://github.com/haoyn231/kde-perfmon)。

The first public release of a Plasma 6 panel monitor for AMD GPUs, powered by `amdgpu_top` and shaped after [kde-perfmon](https://github.com/haoyn231/kde-perfmon).

## 更新内容 / What's Changed

- 面板中显示「图标 + GPU 负载 + 显存占用」，显存可显示百分比或实际容量；负载 ≥70% 变黄、≥90% 变红 / Panel shows icon + GPU load + VRAM, VRAM as percentage or real size, with amber/red thresholds
- 点击 GPU 数字按 GPU 占用打开进程列表，点击显存数字按显存占用打开，再点一次关闭 / Click the GPU number for a GPU-sorted list, the VRAM number for a VRAM-sorted list, click again to close
- 弹窗：环形负载表、显卡型号 / 芯片 / PCIe 链路、边缘温度徽标、显存条、60 秒负载趋势 / Popup with load ring, GPU name / chip / PCIe link, temperature badge, VRAM bar and 60-second history
- 8 个传感器小块：功耗、结温、显存温度、风扇、核心频率、显存频率、电压、GTT / Eight sensor tiles: power, junction temp, memory temp, fan, core clock, memory clock, voltage, GTT
- 进程表支持按显存或 GPU 排序，点击行展开完整命令行、PPID、GTT、媒体引擎占用与显存占比 / Sortable process list; rows expand to show the full command line, PPID, GTT, media-engine usage and VRAM share
- 列表只在最顶上实时刷新，向下滚动即冻结并显示「已暂停 · 回到顶部」 / The list refreshes only at the top; scrolling down freezes it and shows "Paused · back to top"
- 弹窗关闭时不重建进程表，采集进程只写快照 / With the popup closed the process table is not rebuilt; the collector only writes snapshots
- 纯 QML + 一个 Python 采集脚本，不需要编译 C++ 插件 / Plain QML plus one Python collector, no C++ plugin to compile
- 采集进程只在 plasmashell 退出、90 秒没有心跳或收到 SIGTERM 时退出，不留孤儿进程 / The collector exits when plasmashell is gone, after 90 seconds without a heartbeat, or on SIGTERM
- 颜色全部来自 `Kirigami.Theme`，明暗主题与强调色即时跟随 / All colors come from `Kirigami.Theme`; light/dark and accent changes apply instantly

## 安装教程（KDE Plasma 6）

### 环境要求

- KDE Plasma 6（Qt 6.5+）
- [amdgpu_top](https://github.com/Umio-Yasuno/amdgpu_top) ≥ 0.9：`sudo pacman -S amdgpu_top`
- python3（只用标准库）
- 本版本在 Arch Linux / Plasma 6.8.3 / Qt 6.12 / amdgpu_top 0.11.5 上测试

### 从 Release 安装（推荐）

Release 包是纯 QML + Python 脚本，没有需要编译的二进制。

1. 下载本页附件中的 `kde-amdgpu-top-v0.1.0.tar.gz` 与 `kde-amdgpu-top-v0.1.0.tar.gz.sha256`。
2. 校验并解压到当前用户的 Plasma 小程序目录：
   ```bash
   sha256sum -c kde-amdgpu-top-v0.1.0.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-amdgpu-top-v0.1.0.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
   解压后应存在：
   ```
   ~/.local/share/plasma/plasmoids/org.hao.amdgputop/metadata.json
   ~/.local/share/plasma/plasmoids/org.hao.amdgputop/contents/scripts/amdgpu-topd.py
   ~/.local/share/plasma/plasmoids/org.hao.amdgputop/contents/ui/main.qml
   ```
   如果解压后采集脚本没有可执行位，补一下：
   ```bash
   chmod +x ~/.local/share/plasma/plasmoids/org.hao.amdgputop/contents/scripts/amdgpu-topd.py
   ```
3. 让 Plasma 重新加载小程序：
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   也可以注销后重新登录。
4. 右键面板 → **进入编辑模式**（或「添加小组件」）→ 搜索 **AMD GPU 监视器** / **AMD GPU Monitor** → 拖到面板。
5. 点击面板里的 GPU 数字或显存数字，打开详情弹窗。

### 从源码安装

```bash
sudo pacman -S --needed plasma-desktop amdgpu_top python
git clone https://github.com/haoyn231/kde-amdgpu-top.git
cd kde-amdgpu-top
./install.sh
systemctl --user restart plasma-plasmashell.service
```

### 卸载

```bash
rm -rf ~/.local/share/plasma/plasmoids/org.hao.amdgputop
systemctl --user restart plasma-plasmashell.service
```

## Installation (KDE Plasma 6)

### Requirements

- KDE Plasma 6 (Qt 6.5+)
- [amdgpu_top](https://github.com/Umio-Yasuno/amdgpu_top) ≥ 0.9: `sudo pacman -S amdgpu_top`
- python3 (standard library only)
- This build was tested on Arch Linux / Plasma 6.8.3 / Qt 6.12 / amdgpu_top 0.11.5

### Install from the release (recommended)

The release archive is plain QML plus a Python script; there is no binary to compile.

1. Download `kde-amdgpu-top-v0.1.0.tar.gz` and `kde-amdgpu-top-v0.1.0.tar.gz.sha256` from the assets below.
2. Verify and extract the archive into your user Plasma widget directory:
   ```bash
   sha256sum -c kde-amdgpu-top-v0.1.0.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-amdgpu-top-v0.1.0.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
   You should end up with:
   ```
   ~/.local/share/plasma/plasmoids/org.hao.amdgputop/metadata.json
   ~/.local/share/plasma/plasmoids/org.hao.amdgputop/contents/scripts/amdgpu-topd.py
   ~/.local/share/plasma/plasmoids/org.hao.amdgputop/contents/ui/main.qml
   ```
   Restore the executable bit if your extraction lost it:
   ```bash
   chmod +x ~/.local/share/plasma/plasmoids/org.hao.amdgputop/contents/scripts/amdgpu-topd.py
   ```
3. Reload Plasma:
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   Logging out and back in also works.
4. Right-click the panel → **Enter Edit Mode** (or **Add Widgets**) → search for **AMD GPU Monitor** → drag it onto the panel.
5. Click the GPU or VRAM number in the panel to open the popup.

### Build from source

```bash
sudo pacman -S --needed plasma-desktop amdgpu_top python
git clone https://github.com/haoyn231/kde-amdgpu-top.git
cd kde-amdgpu-top
./install.sh
systemctl --user restart plasma-plasmashell.service
```

### Uninstall

```bash
rm -rf ~/.local/share/plasma/plasmoids/org.hao.amdgputop
systemctl --user restart plasma-plasmashell.service
```

## 已知限制 / Known limitations

- 只支持 AMD GPU：数据源 `amdgpu_top` 的能力边界 / AMD GPUs only, limited by `amdgpu_top`
- 进程占用是整卡级统计，不区分图形 / 计算 / 编解码队列 / Per-process numbers are card-wide; graphics, compute and video queues are not separated
- 每秒一帧，适合「看一眼现在什么在吃显存」，不适合帧级性能分析 / One frame per second: good for "what is using my VRAM", not for frame-level profiling
