# kde-amdgpu-top v0.1.1

补丁版本：修复进程列表每秒刷新时的闪烁，其余功能与 v0.1.0 一致。

A patch release that fixes the process list flickering on every refresh; everything else is unchanged from v0.1.0.

## 更新内容 / What's Changed

- 修复：进程列表每秒刷新时会闪一下 / Fixed: the process list flickered on every refresh
  - 原来每秒对 `ListModel` 做 `clear()` + `append()`，所有 delegate 被销毁重建；现在改成按 pid 对账的增量更新（`move` / `insert` / `remove` + 只 `setProperty` 变化的字段），行对象全程保持不动 / The model used to be cleared and refilled every second, destroying and recreating every delegate. It is now reconciled in place by pid (`move` / `insert` / `remove`, then `setProperty` only for changed fields)
  - 去掉了 `add` 的 opacity 淡入动画；排序真的换位时改用 120 ms 的 y 过渡 / Dropped the opacity fade-in on add; genuine reorders now animate with a 120 ms y transition
  - 实测：12 行 × 8 次刷新，delegate 创建次数从 96 次降到 12 次（只创建一次） / Measured: 12 rows × 8 refreshes went from 96 delegate creations to 12 (created once)
- 数据没有变化时直接跳过刷新（保留按字段计算的签名），空闲时几乎不产生重绘 / Unchanged data is skipped entirely via a field-level signature, so an idle list causes almost no repaints

## 安装教程（KDE Plasma 6）

### 环境要求

- KDE Plasma 6（Qt 6.5+）
- [amdgpu_top](https://github.com/Umio-Yasuno/amdgpu_top) ≥ 0.9：`sudo pacman -S amdgpu_top`
- python3（只用标准库）
- 本版本在 Arch Linux / Plasma 6.8.3 / Qt 6.12 / amdgpu_top 0.11.5 上测试

### 从 Release 安装（推荐）

Release 包是纯 QML + Python 脚本，没有需要编译的二进制。

1. 下载本页附件中的 `kde-amdgpu-top-v0.1.1.tar.gz` 与 `kde-amdgpu-top-v0.1.1.tar.gz.sha256`。
2. 校验并解压到当前用户的 Plasma 小程序目录（从旧版本升级时直接覆盖解压即可）：
   ```bash
   sha256sum -c kde-amdgpu-top-v0.1.1.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-amdgpu-top-v0.1.1.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
   解压后应存在：
   ```
   ~/.local/share/plasma/plasmoids/org.hao.amdgputop/metadata.json
   ~/.local/share/plasma/plasmoids/org.hao.amdgputop/contents/scripts/amdgpu-topd.py
   ~/.local/share/plasma/plasmoids/org.hao.amdgputop/contents/ui/main.qml
   ```
   如果解压后采集脚本没有可执行位，补一下：
   ```bash
   chmod +x ~/.local/share/plasma/plasmoids/org.hao.amdgputop/contents/scripts/amdgpu-topd.py
   ```
3. 让 Plasma 重新加载小程序：
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   也可以注销后重新登录。
4. 右键面板 → **进入编辑模式**（或「添加小组件」）→ 搜索 **AMD GPU 监视器** / **AMD GPU Monitor** → 拖到面板。
5. 点击面板里的 GPU 数字或显存数字，打开详情弹窗。

### 从源码安装

```bash
sudo pacman -S --needed plasma-desktop amdgpu_top python
git clone https://github.com/haoyn231/kde-amdgpu-top.git
cd kde-amdgpu-top
./install.sh
systemctl --user restart plasma-plasmashell.service
```

### 卸载

```bash
rm -rf ~/.local/share/plasma/plasmoids/org.hao.amdgputop
systemctl --user restart plasma-plasmashell.service
```

## Installation (KDE Plasma 6)

### Requirements

- KDE Plasma 6 (Qt 6.5+)
- [amdgpu_top](https://github.com/Umio-Yasuno/amdgpu_top) ≥ 0.9: `sudo pacman -S amdgpu_top`
- python3 (standard library only)
- Tested on Arch Linux / Plasma 6.8.3 / Qt 6.12 / amdgpu_top 0.11.5

### Install from the release (recommended)

The release archive is plain QML plus a Python script; there is no binary to compile.

1. Download `kde-amdgpu-top-v0.1.1.tar.gz` and `kde-amdgpu-top-v0.1.1.tar.gz.sha256` from the assets below.
2. Verify and extract it into your user Plasma widget directory (extracting over an older version upgrades in place):
   ```bash
   sha256sum -c kde-amdgpu-top-v0.1.1.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-amdgpu-top-v0.1.1.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
   You should end up with:
   ```
   ~/.local/share/plasma/plasmoids/org.hao.amdgputop/metadata.json
   ~/.local/share/plasma/plasmoids/org.hao.amdgputop/contents/scripts/amdgpu-topd.py
   ~/.local/share/plasma/plasmoids/org.hao.amdgputop/contents/ui/main.qml
   ```
   Restore the executable bit if your extraction lost it:
   ```bash
   chmod +x ~/.local/share/plasma/plasmoids/org.hao.amdgputop/contents/scripts/amdgpu-topd.py
   ```
3. Reload Plasma:
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   Logging out and back in also works.
4. Right-click the panel → **Enter Edit Mode** (or **Add Widgets**) → search for **AMD GPU Monitor** → drag it onto the panel.
5. Click the GPU or VRAM number in the panel to open the popup.

## 已知限制 / Known limitations

- 只支持 AMD GPU：数据源 `amdgpu_top` 的能力边界 / AMD GPUs only, limited by `amdgpu_top`
- 进程占用是整卡级统计，不区分图形 / 计算 / 编解码队列 / Per-process numbers are card-wide; graphics, compute and video queues are not separated
- 每秒一帧，适合「看一眼现在什么在吃显存」，不适合帧级性能分析 / One frame per second: good for "what is using my VRAM", not for frame-level profiling
